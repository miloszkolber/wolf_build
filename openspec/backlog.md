- Recheck the pinned shared-gate digest each review: the gate publisher serves only its recent versions, so a pinned consumer digest can disappear from the registry without any gate source change.
- Desktop Shift+Tab overlay investigation and client-disconnection diagnosis remain outside the scope of the [session idle and Gamescope change](changes/archive/2026-11-02-session-idle-and-gamescope/proposal.md), which includes the accepted Big Picture compositor repair.
- Review Wolf's [control packet sequence and IV handling](https://github.com/games-on-whales/wolf/blob/db709cfd3f0f49dfd7d00495940119309692b535/src/moonlight-protocol/moonlight/control.hpp) against the Moonlight protocol. The reviewed source uses only one byte of the sequence for the GCM IV, while [outgoing control](https://github.com/games-on-whales/wolf/blob/db709cfd3f0f49dfd7d00495940119309692b535/src/moonlight-server/control/control.cpp) always passes sequence zero. [Moonlight's control implementation](https://github.com/moonlight-stream/moonlight-common-c/blob/master/src/ControlStream.c) explicitly truncates to one byte for legacy Nvidia compatibility and uses a different IV format when control V2 is negotiated. Nonce reuse can weaken GCM confidentiality and authentication. A compatible fix and real-client evidence are needed before changing protocol behavior; no practical forgery is claimed.
- Review authenticated input-structure bounds after the pre-authentication length backport. [Upstream PR 570](https://github.com/games-on-whales/wolf/pull/570) identifies authenticated input parsing as a separate follow-up.
- Recheck Ubuntu's [bubblewrap CVE-2026-87766](https://ubuntu.com/security/CVE-2026-87766) and the [2026-11-10 Xwayland advisory](https://lists.x.org/archives/xorg-announce/2026-November/003759.html) against the exact installed package versions and distribution backports. Ubuntu 26.04 reported bubblewrap vulnerable and CVE-2026-109094 needs evaluation during the 2026-11-16 review. Do not weaken sandboxing or infer workload exploitability from package presence alone.
- Verify Steam's updated 64-bit nested runtime with a real first login and existing home, Proton, audio and the target user-namespace policy. Fake-app and package checks do not prove this acceptance, and i386 game dependencies remain required.
- Recheck Ubuntu's [libva CVE-2026-56438](https://ubuntu.com/security/CVE-2026-56438) for both application-image ABIs and evaluate whether configured consumers exercise the Intel [HEVC](https://github.com/intel/media-driver/commit/2a32c7fafd8fa169112e962587777969cc8c654f) or [AVC](https://github.com/intel/media-driver/commit/1768cc6b2d5446f8a9629129db9f315aadbee8d8) decode paths fixed in the unreleased `26.4.2` tag. Do not mix an unreviewed Intel stack or infer exploitability from library presence.
