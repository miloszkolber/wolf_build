- Desktop Shift+Tab overlay investigation and client-disconnection diagnosis remain outside the scope of the [session idle and Gamescope change](changes/archive/2026-11-02-session-idle-and-gamescope/proposal.md), which includes the accepted Big Picture compositor repair.
- Review Wolf's [control packet sequence and IV handling](https://github.com/games-on-whales/wolf/blob/db709cfd3f0f49dfd7d00495940119309692b535/src/moonlight-protocol/moonlight/control.hpp) against the Moonlight protocol. The reviewed source uses only one byte of the sequence for the GCM IV, while [outgoing control](https://github.com/games-on-whales/wolf/blob/db709cfd3f0f49dfd7d00495940119309692b535/src/moonlight-server/control/control.cpp) always passes sequence zero. [Moonlight's control implementation](https://github.com/moonlight-stream/moonlight-common-c/blob/master/src/ControlStream.c) explicitly truncates to one byte for legacy Nvidia compatibility and uses a different IV format when control V2 is negotiated. Nonce reuse can weaken GCM confidentiality and authentication. A compatible fix and real-client evidence are needed before changing protocol behavior; no practical forgery is claimed.
- Review Wolf's pre-authentication control packet length checks against received ENet buffer sizes. [Upstream PR 558](https://github.com/games-on-whales/wolf/pull/558) identifies this as a separate follow-up. The authentication backport does not by itself prove malformed-packet safety.
